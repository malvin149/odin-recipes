# Odin Recipes
A simple HTMl project showcasing three delicious recipes with a clean, structured layout demonstrated foundational web development skills through semantic HTML and proper content organization. 

### Project Overview 
This is a practice project from [The Odin Project's Foundation curriculum](https://www.theodinproject.com/). The goal was too build a recipe website that displays multiple recipes with ingredients, preparation steps, and images.

#### Current Version: 
Foundations refresher with step-by-step learning commits

### Features
- **Three Recipe Pages**: Italian Spaghetti and Meatballs, classic Lasagna, and Chocolate Chip Cookies
- **Semantic HTML**: Proper use of HTML5 elements (`<figure>`, `<figcaption>`, `<ol>`, `<ul>`)
- **Responsive Images**: Recipe images with descriptive alt text
- **Recipe Attribution**: Proper credit to original sources (Allrecipes)
- **Clean Navigation**: Home links on each recipe page for easy navigation
- **HTML Entities**: Proper use of fraction entities (&frac12;, &frac14;, &frac38;, etc) for ingredient measurements

```bash

```
2. Navigate to the project directory:
```bash
cd odin-recipes
```
3. Open `index.html` in your web browser.
